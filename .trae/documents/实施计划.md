# 教材改编工具 - 实施计划

**版本**: 1.0
**日期**: 2026-05-16

---

## 项目概览

本项目基于 [设计规格书](file:///workspace/docs/superpowers/specs/2026-05-16-教材改编工具-design.md)，采用模块化流水线架构开发桌面应用。

---

## 技术栈

| 层级 | 技术选型 | 说明 |
|-----|---------|------|
| 桌面框架 | Tauri | Rust 后端 + Web 前端 |
| 前端 | React 18 + TypeScript | 构建用户界面 |
| UI 组件库 | shadcn/ui + Tailwind CSS | 现代美观的界面 |
| 富文本编辑器 | TipTap/ProseMirror | 强大的编辑功能 |
| 本地数据库 | SQLite (via rusqlite) | 结构化数据存储 |
| 文档解析 | pdf.js + mammoth.js | PDF/Word 读取 |
| 文档导出 | docx.js + markdown-it | 多格式导出 |
| 状态管理 | Zustand | 轻量级状态管理 |

## 实施阶段

### 阶段 1：项目初始化与基础架构

**目标**：搭建开发环境，建立项目骨架

| 任务 | 详细说明 |
|-----|---------|
| 1.1 初始化 Tauri 项目 | 使用 create-tauri-app 创建项目 |
| 1.2 配置 React + TypeScript | 确保 TS 严格模式，配置路径别名 |
| 1.3 集成 Tailwind CSS + shadcn/ui | 配置样式系统 |
| 1.4 搭建基础目录结构 | 创建 features/components/stores 等目录 |
| 1.5 配置开发环境 | Prettier, ESLint, 开发脚本 |

**预期产出**：可运行的基础桌面应用

---

### 阶段 2：本地存储模块

**目标**：实现数据持久化方案

| 任务 | 详细说明 |
|-----|---------|
| 2.1 设计数据库 schema | 讲义表、章节表、版本历史表、配置表 |
| 2.2 实现 SQLite 初始化 | rusqlite 集成，连接池管理 |
| 2.3 实现数据库模型 | Lectures, Chapters, Versions 等 |
| 2.4 实现 Tauri 命令层 | 定义 CRUD 命令供前端调用 |
| 2.5 实现文件系统管理 | 讲义内容存储路径管理 |
| 2.6 前端集成存储 Hook | useLecture, useChapter 等 |

**数据库设计要点**：
- lectures: id, title, created_at, updated_at, tags
- chapters: id, lecture_id, title, content, order, created_at
- versions: id, chapter_id, content, created_at, message

## 关键技术决策记录

### 1. 富文本编辑器选择

**选择**: TipTap (基于 ProseMirror)
**理由**: 功能强大，生态完善，支持 Markdown 双向转换

### 2. 状态管理

**选择**: Zustand
**理由**: 轻量级，TypeScript 支持好，无需大量样板代码

### 3. PDF 处理

**选择**: pdf.js (浏览器端)
**理由**: 成熟稳定，支持渲染和文本提取
