# 教材改编工具 - Brainstorming 计划

## 目标
帮助教师设计一款软件，将大型教材改编成可修改订正的讲义。

## Brainstorming 流程

### 1. 探索项目上下文
- [ ] 检查工作目录当前状态
- [ ] 确认是新项目还是已有项目基础

### 2. 询问澄清问题（一次一个）
- [ ] Q1: 教材格式（PDF/Word/网页/混合）
- [ ] Q2: 改编的核心需求（精简内容/提取重点/结构调整/格式转换）
- [ ] Q3: 讲义的输出格式需求
- [ ] Q4: 是否需要 AI 辅助功能
- [ ] Q5: 单机使用还是多用户协作

### 3. 方案对比与推荐
- [ ] 提出 2-3 种技术方案
- [ ] 分析各方案优缺点
- [ ] 给出推荐建议

### 4. 展示设计方案
- [ ] 架构设计
- [ ] 核心功能模块
- [ ] 数据流设计
- [ ] 用户界面概念

### 5. 输出设计文档
- [ ] 编写 spec 设计文档
- [ ] 保存到 `docs/superpowers/specs/YYYY-MM-DD-教材改编工具-design.md`
- [ ] 提交到 git

### 6. 用户审核
- [ ] 等待用户审核设计文档
- [ ] 根据反馈修改

### 7. 过渡到实施计划
- [ ] 调用 writing-plans skill 创建实施计划
