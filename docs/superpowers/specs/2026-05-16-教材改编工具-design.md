## 1. 项目概述

### 1.1 项目背景

教师需要将大型教材改编成适合课堂教学的讲义，这一过程通常涉及内容精简、结构调整、格式转换等多个环节。目前缺乏专门的工具来高效完成这些任务。

### 1.2 项目目标

开发一款面向教师的桌面应用，帮助用户：
- 从多种格式的教材中提取内容
- 借助 AI 辅助将教材改编为讲义
- 支持灵活的编辑和订正
- 多格式导出讲义
- 支持多设备同步和团队协作

### 1.3 核心原则

- **本地优先**：数据默认存储在本地，支持离线使用
- **隐私保护**：敏感内容不强制上传云端
- **灵活协作**：可选的云端同步功能

## 2. 技术架构

### 2.1 应用类型

本地优先的跨平台桌面应用

### 2.2 架构模式

模块化流水线架构，各功能模块独立且可组合：

```
┌─────────────────────────────────────────────────────────┐
│                      桌面应用                             │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐    │
│  │ 导入模块 │  │ AI改编  │  │ 编辑器  │  │ 导出模块 │    │
│  │ PDF     │  │ 模块    │  │        │  │ Word    │    │
│  │ Word    │  │        │  │        │  │ PDF     │    │
│  │ 网页    │  │        │  │        │  │ PPT     │    │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘    │
│       │           │           │           │            │
│       └───────────┴─────┬─────┴───────────┘            │
│                         │                              │
│                  ┌──────┴──────┐                       │
│                  │   本地存储   │                       │
│                  │ (讲义仓库)   │                       │
│                  └──────┬──────┘                       │
└─────────────────────────┼─────────────────────────────┘
                          │
              ┌───────────┴───────────┐
              │      可选云端同步        │
              │  (多设备/团队协作)       │
              └───────────────────────┘
```

### 2.3 技术选型

**桌面框架**：Tauri（Rust 后端 + Web 前端）
- 轻量、安全、跨平台
- 支持本地 AI 模型集成

**前端**：React + TypeScript
- 响应式界面
- 丰富的编辑器生态

**本地存储**：SQLite
- 结构化数据存储
- 支持全文搜索

**文件存储**：Markdown + JSON
- 便于版本控制
- 易于迁移

**AI 集成**：支持多种 AI 服务
- OpenAI API
- 本地模型（Llama 等）

## 3. 功能模块

### 3.1 导入模块

| 功能 | 描述 |
|-----|------|
| PDF 导入 | 解析 PDF 文件，提取文本、图像和结构信息 |
| Word 导入 | 读取 .docx 文件，保留基本格式 |
| 网页导入 | 抓取网页内容，清洗无关元素 |
| 批量导入 | 支持一次导入多个文件 |

**技术要点**：
- PDF 解析使用 pdf-parse 或 pdf.js
- Word 解析使用 mammoth.js
- 网页抓取使用 Playwright 或类似工具

### 3.2 AI 改编模块

| 模式 | 描述 |
|-----|------|
| AI 辅助 | 自动识别章节、提取重点、建议精简内容，用户确认后应用 |
| 完全 AI | AI 自动完成改编，用户审核和调整 |

**核心功能**：
- 自动识别章节结构和层级关系
- 提取核心知识点和关键概念
- 智能内容精简和改写
- 保留或标注重要公式、图表
- 生成讲义大纲建议

**工作流程**：
1. 用户选择改编模式（辅助/全自动）
2. AI 分析教材内容
3. 生成改编建议或完整讲义
4. 用户审核、修改、确认
5. 保存到本地讲义库

### 3.3 编辑器

**核心功能**：
- 富文本编辑（标题、段落、列表、代码块等）
- 讲义大纲管理（拖拽调整章节顺序）
- 版本历史（查看、对比、回滚）
- 批注与评论（用于团队协作）
- 实时预览

**编辑模式**：
- 分栏视图：左侧大纲导航，右侧内容编辑
- 专注模式：隐藏侧边栏，专注当前章节
- 大纲模式：仅显示结构，快速定位

### 3.4 导出模块

| 格式 | 描述 |
|-----|------|
| Word (.docx) | 保留格式，可继续编辑 |
| Markdown (.md) | 纯文本，便于版本管理 |
| PDF | 固定排版，适合打印或分发 |
| PPT (.pptx) | 分页幻灯片，适合课堂演示 |

**导出选项**：
- 自定义模板
- 选择性导出（部分章节）
- 批量导出

## 4. 数据管理

### 4.1 本地存储

**数据库**：SQLite
- 讲义元数据（标题、创建时间、修改时间、标签等）
- 章节结构
- 版本记录
- 用户设置

**文件系统**：
- 讲义内容存储为 Markdown 文件
- 导入的原始文件备份
- 导出的文件

### 4.2 云端同步（可选）

**同步策略**：
- 默认关闭，用户主动启用
- 端到端加密传输
- 冲突解决机制（最后修改优先或手动合并）

**同步内容**：
- 讲义数据
- 用户设置（可选）

**不同步**：
- 导入的原始教材文件
- 本地 AI 模型缓存

## 7. 风险与注意事项

### 7.1 技术风险

| 风险 | 缓解措施 |
|-----|---------|
| PDF 解析质量不稳定 | 支持多种解析库，提供备选方案 |
| AI API 成本控制 | 本地模型支持，优化调用策略 |
| 跨平台兼容性 | 使用 Tauri 确保跨平台一致性 |

### 7.2 用户体验

- 离线优先，确保无网络时核心功能可用
- 渐进式功能引导，降低学习成本
- 重要操作提供撤销功能
